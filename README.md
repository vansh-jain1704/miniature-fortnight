# React Lab Manual (BCSL657B)

This repository contains React programs based on the VI Semester lab manual (CBCS 2025–2026). Each program demonstrates key React concepts with step-by-step implementation and commands.

## Prerequisites
- Node.js installed
- npm or npx available
- VS Code or any code editor

## Program 1: Dynamic Text Display (useState)
Steps:
1. Create React app
2. Add input field and state
3. Update UI dynamically

Commands:
npx create-react-app my-dynamic-app
cd my-dynamic-app
npm start

## Program 2: Props (Parent → Child Components)
