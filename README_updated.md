# React Lab Manual (BCSL657B)

This repository contains React programs with step-by-step commands included in each step.

## Program 1: Dynamic Text Display (useState)
1. Create React app:
   npx create-react-app my-dynamic-app
2. Move into folder:
   cd my-dynamic-app
3. Run project:
   npm start
