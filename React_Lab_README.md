# React Lab Manual – Execution Guide (BCSL657B)

## Prerequisites

1. Install Node.js from https://nodejs.org  
2. Verify installation  
   - node -v  
   - npm -v  
3. Open VS Code  
4. Open terminal (Ctrl + `)

---

# Program 1: Dynamic Text Display

1. Create project  
   npx create-react-app my-dynamic-app  

2. Move into project  
   cd my-dynamic-app  

3. Open in VS Code  
   code .  

4. Open file  
   src/App.js  

5. Replace entire content with given program  

6. Run  
   npm start  

---
